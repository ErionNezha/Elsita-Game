# 💖 Operacioni: FALJE 🇦🇱

Një lojë e vogël (dhe shumë serioze 😄) për të kërkuar falje — kap zemrat, shmang inatet, fito faljen.

![Pamje nga demo](screenshot.png)

🎮 **Luaje live:** https://elsita-game.netlify.app

## 🎯 Si luhet

- **Niveli 1/3** — Kap zemrat 💗 që t'ia zbusësh zemrën. Shmang inatet 💣 se e rrisin shkallën e inatit!
- **Niveli 2** — Po zbutet pak… mos e prish!
- **Niveli 3** — Zemra u zbut! Mbetet vetëm një pyetje…
- **Finalja** — "Elsita, më fal?" 🧎‍♂️💐
  - Butoni **"Po"** → MË FALI!!! 🎉
  - Butoni **"Jo"** → është nën stres, lëviz vetë 😏

Po kape shumë inate, Elsita të mbyll derën 🚪😤 dhe e nis nga e para.

## 🛠️ Teknologjitë

- **HTML + CSS + JavaScript** — një file i vetëm `index.html`, pa dependencies
- **Canvas** për gameplay-n (zemrat dhe inatet që bien)
- **Web Audio API** për efektet e zërit (pa file audio të jashtëm)
- Fotoja e ekranit të fitores është e futur brenda file-it (base64)

## 📁 Struktura

```
Elsita-Game/
├── index.html   # e gjithë loja — hap me browser dhe luaj
└── README.md
```

# 💖 Operation: FORGIVENESS 🇬🇧

A small (and very serious 😄) game for asking forgiveness — catch the hearts, dodge the grudges, earn forgiveness.

🎮 **Play live:** https://elsita-game.netlify.app

## 🎯 How to play

- **Level 1/3** — Catch the hearts 💗 to soften her heart. Dodge the grudges 💣, they raise the grudge meter!
- **Level 2** — She's softening a bit… don't ruin it!
- **Level 3** — Her heart is softened! Only one question remains…
- **Finale** — "Elsita, forgive me?" 🧎‍♂️💐
  - The **"Yes"** button → SHE FORGAVE ME!!! 🎉
  - The **"No"** button → it's stressed, it moves on its own 😏

Catch too many grudges and Elsita slams the door 🚪😤 and you start over.

## 🛠️ Tech

- **HTML + CSS + JavaScript** — a single `index.html` file, no dependencies
- **Canvas** for gameplay (falling hearts and grudges)
- **Web Audio API** for sound effects (no external audio files)
- The victory screen image is embedded in the file (base64)

## 📁 Structure

```
Elsita-Game/
├── index.html   # the whole game — open in a browser and play
└── README.md
```
