# 💖 Operacioni: FALJE

Një lojë e vogël (dhe shumë serioze 😄) për të kërkuar falje — kap zemrat, shmang inatet, fito faljen.

🎮 **Luaje live:** https://elsita-game.netlify.app

## 🎯 Si luhet

- **Niveli 1/3** — Kap zemrat 💗 që t'ia zbusësh zemrën. Shmang inatet 💣 se e rrisin shkallën e inatit!
- **Niveli 2** — Po zbutet pak… mos e prish!
- **Niveli 3** — Zemra u zbut! Mbetet vetëm një pyetje…
- **Finalja** — "Elsita, më fal?" 🧎‍♂️💐
  - Butoni **"Po"** → MË FALI!!! 🎉
  - Butoni **"Jo"** → është nën stres, lëviz vetë 😏

Po kape shumë inate, Elsita të mbyll derën 🚪😤 dhe e nis nga e para.

## 🛠️ Teknologjitë

- **HTML + CSS + JavaScript** — një file i vetëm `index.html`, pa dependencies
- **Canvas** për gameplay-n (zemrat dhe inatet që bien)
- **Web Audio API** për efektet e zërit (pa file audio të jashtëm)
- Fotoja e ekranit të fitores është e futur brenda file-it (base64)
